# Security Policy

## Supported Versions

Security fixes are prioritized for the most recent development state on `main`.

## Reporting a Vulnerability

Please do not open public issues for security-sensitive reports.

Send vulnerability reports to:
- security@short-finance.local

Include:
- A clear description of the issue.
- Reproduction steps or proof of concept.
- Potential impact.
- Suggested mitigations if available.

## Response Process

1. Acknowledgement within 5 business days.
2. Initial triage and severity assessment.
3. Fix planning and coordinated disclosure.
4. Public advisory after a fix is available, when appropriate.
